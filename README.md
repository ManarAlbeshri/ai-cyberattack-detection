# AI-Based Cyberattack Detection and Defense System

## Overview
This graduation project presents an intelligent cybersecurity system designed to detect and classify cyberattacks using Artificial Intelligence and Machine Learning techniques. The system focuses on improving network security by analyzing traffic behavior and identifying malicious activities in real time.

## Objectives
- Detect cyberattacks with high accuracy
- Classify different attack types using AI models
- Improve response speed and threat mitigation
- Enhance system reliability and security monitoring

## Technologies Used
- Python
- Machine Learning
- Deep Learning
- Scikit-learn
- TensorFlow / Keras
- Pandas & NumPy
- CICDDoS2019 Dataset
- UNSW-NB15 Dataset

## Features
- Real-time attack detection
- Intelligent traffic analysis
- Automated classification of attacks
- Performance evaluation using multiple algorithms
- Visualization of results and metrics

## Results
The implemented models achieved high accuracy in detecting and classifying cyberattacks using multiple evaluation metrics such as Accuracy, Precision, Recall, and F1-Score.
